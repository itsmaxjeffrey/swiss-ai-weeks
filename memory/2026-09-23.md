## Lessons

- pandas 3.x: `Series.map` on mixed str/None columns coerces None→NaN;
  keep date/parse helpers type-defensive.
- Feed formats bite: URLhaus puts its CSV header in a `#` comment line —
  always inspect raw file heads before writing parsers.
- Pipe background exec through `tail` and you lose live progress in `process
  poll` (tail buffers until exit) — poll the raw session instead.
